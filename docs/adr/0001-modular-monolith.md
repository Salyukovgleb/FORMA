# ADR-0001: Модульный монолит

Владелец: backend architect / backend-developer. Статус: draft. Обновлено: 2026-10-30.
Связи: BE-002–BE-007; ADR-0001–0007; проверки и задачи в [карте](../tasks/ROADMAP.md).

## Контекст

Один разработчик, общие транзакции и release; микросервисы увеличивают эксплуатацию.

## Варианты

Модульный монолит; микросервисы; единый файл приложения.

## Решение

FastAPI modules с application/domain/infrastructure, isolated workers одного release.

## Последствия и цена поддержки

Нет сетевых вызовов между доменами; нужна дисциплина импортов/UoW.

## Критерий пересмотра

Независимые команды/нагрузка требуют самостоятельного релиза домена.

## Проверка

BE-003/006/007 проектируют; соответствующие implementation gates описаны в [карте](../tasks/ROADMAP.md). Решение draft, применение в продукте planned.
