# Продукт и MVP

Владелец: backend architect / backend-developer. Статус: draft. Обновлено: 2026-10-30.
Связи: BE-002–BE-007; ADR-0001–0007; проверки и задачи в [карте](tasks/ROADMAP.md).

FORMA — backend редактора научных документов: LaTeX → PDF, редактируемый DOCX и исходники ZIP.
Один разработчик, frontend отдельно. Пользователь регистрируется, создаёт проект/шаблон,
ведёт дерево файлов, сохраняет текст с защитой от конфликтов, запускает сборку и скачивает результат.
Owner управляет участниками и удалением; editor изменяет исходники; viewer читает и экспортирует.

| История | Проверяемый результат | Требование |
|---|---|---|
| Войти и отозвать устройство | Ранее выданный access token перестаёт работать после revoke | FR-AUTH-001 |
| Создать статью | Пустой проект либо versioned sample с выбранным main.tex | FR-PRJ-001 |
| Сохранить из двух вкладок | Только один PUT с revision N успешен; второй 409 | FR-FILE-001 |
| Переименовать папку | Пути всего поддерева меняются атомарно | FR-FILE-002 |
| Скомпилировать | Snapshot не меняется при последующих save | FR-DOC-001 |
| Экспортировать Word | Абзацы/таблицы/формулы редактируются в OOXML | FR-DOC-002 |
| Поделиться | Viewer не может редактировать или выдавать роли | FR-ACL-001 |
| Удалить проект | 7 суток доступен owner для restore, затем purge | FR-PRJ-002 |

Не входят: realtime CRDT/OT, visual editor, AI, OAuth, почтовые приглашения, сложный diff.
Смена владельца и удаление аккаунта также вне MVP. Письма/forgot password не обещаются;
до публичного запуска нужен согласованный административный recovery-процесс.
